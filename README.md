System Requirements
1..NET SDK
2.Visual Studio Community or VS Code

 Setting Up the System
1.Install Visual Studio or Visual Studio Code.
2.Install the .NET SDK.
3.Download or clone the Choke King project from GitHub.
4.Open the project folder in your development environment.
5.Make sure Program.cs is included in the project.
6.Open the terminal in the project folder.

Launching the System Using dotnet run
1.Open the terminal.
2.Navigate to the project directory.
3.Run the dotnet run
4.Wait for the program to compile and launch.
5.The main menu will appear.
